# CampusPulse

### Campus Communication, Connected

CampusPulse is a campus notification platform designed to make communication between educational institutions and students more organized, accessible, and efficient.

It provides a dedicated frontend for campus announcements, academic updates, events, and other important information through a centralized interface.

## Live Demo

**Website:** https://campus-pulse-pratyush.vercel.app/

## Overview

CampusPulse aims to simplify how campus-related information reaches students.

By bringing notifications into one accessible environment, the platform helps students stay informed and connected with campus activities.

## Features

- Centralized interface for campus notifications.
- Student-focused user experience.
- React-based frontend architecture.
- Dedicated logging middleware component.
- Responsive interface for different screen sizes.
- Modern frontend development workflow.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/pratyush61/campus-pulse.git
```

### Navigate to the Frontend

```bash
cd campus-pulse/notification_app_fe
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
